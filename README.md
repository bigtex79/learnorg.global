# learnorg.global — rebuilt static site

Rebuilt on 2026-11-18 from Wayback Machine captures of learnorg.global. The live site has shown a "Site is undergoing maintenance" page since Nov 2025, and its HTTPS currently fails.

- **Text source:** the last full WordPress version, captured 9 Oct 2025.
- **Image source:** the Wayback Machine kept almost none of the WordPress images, so the images in `assets/img/` were re-downloaded from the old Wix site's media CDN (static.wixstatic.com).
- **Format:** plain HTML/CSS/JS. No build step and no server code. Upload the whole folder to any static host (Netlify, Cloudflare Pages, GitHub Pages, cPanel `public_html`, …).

## What was changed from the archived site
- Removed leftover placeholder content from the "Creote" WordPress theme: lorem-ipsum blocks, the fake pricing tables, testimonials and team members, the "61W Business Str Hobert, LA" address, and a demo "World Sport Tourism Congress" event.
- Fixed obvious typos (e.g. "OBEY Association" → "Obeya Association", "leding" → "leading").
- Buttons that pointed at the old `newsite.lcm-ilo.com` staging domain, or at `#`, now go to the right page here.
- Client logos (UDI, Equinor, Yara and others) were never archived. Clients are shown as text cards.
- There is no mailing-list signup or contact form, because these need a backend. Contact goes through email and phone links.

## Downloads (PDFs and Office files)
- **Source:** the Wix site's own file storage, plus Samer's backup of the Wix site (`learnorg-backup.zip`, 85 files, Feb 2025). The Wayback Machine cut many PDFs off at 1 MB, so complete copies were used.
- **`assets/pdf/`** holds 23 PDFs: ILO's course material (Lean ledelse Del I, Systems Thinking with Obeya chapter resources) and 8 articles by other authors that the old site hosted and the book pages refer to (Laloux, Tanaka, Cabrera, Rother, VMCL, VINT, a Digital Obeya paper, A3 SoPK notes). At the client's request these are all published again.
- **`assets/files/`** holds 7 Word, PowerPoint and Excel files from the backup (Obeya articles list, Obeya self-assessment, VSM and VMCL/Hoshin presentations, Lean ledelse Del II and III, Lean-speil Excel template).
- Everything is listed under Open Resources → Library, and linked from the book pages where the old site linked it.
- **Duplicates:** "Historisk bakgrunn" and "Lean Ledelse" were the same file on the old site, so it appears only once.

## Editing
The page HTML is generated by `tools/build.py`, which writes the same header and footer onto every page. You can edit a page's `index.html` directly. Or change the content in `tools/build.py` and regenerate all pages:

```bash
python3 tools/build.py .
```

Rebuilding overwrites every page's `index.html`, so pick one approach and stick with it. Styles live in `assets/css/style.css`.

The text of the book resource pages lives in `tools/content/books/` as HTML fragments, one per page. `build.py` wraps them in the page layout. Their images are in `assets/img/books/`.
